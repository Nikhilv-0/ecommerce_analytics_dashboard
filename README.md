# E-Commerce Sales & Customer Analytics

An end-to-end data analytics project analyzing e-commerce sales, customers, products, orders, payments, and profitability using **MySQL and Power BI**.

## Tools Used

- MySQL
- Power BI
- SQL
- DAX
- Power Query

## Analysis

The project covers:

- Revenue and profit analysis
- Monthly and yearly sales trends
- Product and category performance
- Customer analysis
- State and city-wise sales
- Payment method analysis
- Order status analysis
- Year-over-year revenue growth

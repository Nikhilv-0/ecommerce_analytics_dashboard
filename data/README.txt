E-Commerce Sales & Customer Analytics — Power BI Project

Synthetic practice dataset.

Files:
customers.csv = 10,000 customers
products.csv = 1,000 products
orders.csv = 100,000 orders
payments.csv = 100,000 payments
date.csv = calendar table (2022–2024)

Project workflow:
1. Import CSVs into Power BI
2. Clean/check data in Power Query
3. Build a star-schema model
4. Create DAX measures
5. Build Executive, Customer, and Product dashboards
6. Use SQL for business analysis and validation
